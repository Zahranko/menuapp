# Brand assets

Files for the current brand (see `brand.json` and docs/PLAN.md section 0):

- `logo.svg`: wordmark used on the marketing site, emails and back office
- `app-icon.png`: 1024x1024 app icon, used by `scripts/rebrand.sh`
- `favicon.svg`: browser icon for the marketing site

To rename the product, replace these files and edit `brand.json`, then run `scripts/rebrand.sh`.
