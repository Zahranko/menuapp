# S16+ · Template factory (templates 002 to 100)

**Depends on:** S08, S13. **Branch:** `session/s16-templates-<from>-<to>` (for example `session/s16-templates-002-006`)

## Goal
Add 4 to 6 new templates per session. Each template has its own layout and its own way of showing products, never a recolor of another.

## Read first
`templates/souq/` as the reference implementation. PLAN.md section 6. `docs/templates-catalog.md` (create it in the first factory session: one row per number 002–100 with name, business type, product display idea, status).

## Build, per template
1. `manifest.json` reusing standard field keys where they make sense (`font`, `theme`, `accent`, `hero.*`, `sections`) and adding template-specific ones.
2. Sections and product display unique to the template. Examples of display ideas: text-only price list with dotted leaders, large photo cards in a horizontal carousel per category, catalog grid with filters and sizes for shops, chalkboard-style board, magazine layout with story cards, compact two-column bakery case.
3. Works with 1 to 200 products, long names, missing photos, Arabic RTL, all themes.
4. Thumbnail generated by a Playwright script from fixture data.
5. Registry rebuilt; the backend picks it up without code changes.

## Done when
- `scripts/brand-lint.sh` passes (no hardcoded brand name or domain).
- All `apps/sites` checks pass, Playwright smoke test covers the new templates.
- Screenshots of each new template (mobile and desktop) in the PR. `docs/templates-catalog.md` and `docs/STATUS.md` updated.
